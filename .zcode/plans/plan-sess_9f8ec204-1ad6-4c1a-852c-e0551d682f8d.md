## 将主背景替换为 WebGL 粒子动画

### 1. 安装依赖
```bash
npm install ogl
```
仅安装 `ogl`（WebGL 库），不引入 React。

### 2. 新建 `src/components/ParticlesBackground.astro`
- 使用 ogl 原生 JS 实现粒子动画（改写自 React Bits Particles 组件）
- 全屏 fixed 定位，z-index 置于最底层
- 默认配色匹配博客 Decora 风格（青/黄/粉）
- 支持 Props 自定义：颜色、粒子数量、速度、扩散范围等
- 包含 resize 和 cleanup 处理

### 3. 修改 `src/styles/global.css`
- `body` 背景改为 `transparent`
- `--bg-primary` 改为半透明深色 `rgba(10, 10, 12, 0.88)`

### 4. 修改 `src/layouts/BaseLayout.astro`
- `<body>` 顶部加入 `<ParticlesBackground />`
- 内容区使用半透明背景，让粒子可见
- 波浪 SVG fill 色与半透明背景匹配
